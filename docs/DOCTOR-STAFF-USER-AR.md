# دليل الطبيب · الموظف · المستخدم

## الفكرة في سطر واحد

```
مستخدم (User)  ← اختياري — للدخول للنظام
    └── موظف (Staff)  ← هوية في العيادة (دور: doctor)
            └── طبيب (Doctor)  ← بيانات سريرية (تخصص، ترخيص، غرفة)
```

- **المستخدم:** البريد وكلمة المرور وصلاحية Spatie (`doctor`, `receptionist`, …).
- **الموظف:** الاسم في قوائم الرواتب والطاقم، الهاتف، الربط بحساب المستخدم.
- **الطبيب:** سجل سريري مرتبط بالموظف؛ المواعيد والزيارات تعتمد عليه.

---

## الطريقة الصحيحة: إضافة طبيب جديد (مع دخول للنظام)

1. من القائمة: **الأطباء** → **إضافة طبيب**  
   أو **الموظفون** → **إضافة طبيب**  
   أو الرابط: `/doctors/onboarding/create`

2. اختر أحد الخيارين:
   - **حساب جديد:** الاسم + البريد (مرة واحدة) + كلمة المرور + بيانات سريرية.
   - **مستخدم موجود:** إن أنشأت المستخدم من **المستخدمون** بدور طبيب، يظهر هنا للربط.

3. اضغط **حفظ وإنهاء**.

النظام ينشئ تلقائياً: `User` + دور `doctor` + `Staff` (دور doctor) + `Doctor` (بيانات سريرية).

---

## إضافة موظف بدون طبيب

**الموظفون** → **إضافة موظف** — اختر دوراً مثل: استقبال، محاسب، ممرض، …  
لا يظهر دور «طبيب» في هذه الشاشة عمداً.

---

## تعديل طبيب موجود

| ماذا تريد | أين |
|-----------|-----|
| تخصص، ترخيص، غرفة، ملاحظات | **الموظفون** → تعديل الموظف (دور طبيب) → قسم **بيانات الطبيب السريرية** → **تحديث** |
| الاسم، هاتف، بريد الموظف | نفس شاشة تعديل الموظف (القسم العلوي) |
| كلمة المرور أو بريد الدخول | **المستخدمون** → تعديل المستخدم المرتبط |
| ربط حساب دخول لطبيب بدون مستخدم | **معالج إضافة طبيب** → «ربط مستخدم موجود» |

---

## منح دخول لطبيب أضفته كموظف (حالتك الشائعة)

1. أضفت **موظف طبيب** من الموظفون / الأطباء ← ظهر في قائمة الأطباء ✓  
2. **المستخدمون** → **إضافة مستخدم**  
3. اختر **ربط موظف موجود**  
4. من القائمة اختر **د. قيس** (الاسم والبريد يتعبّون تلقائياً)  
5. أدخل **كلمة المرور** فقط → **إنشاء المستخدم**

> إذا لم يظهر الموظف: تأكد أن سجل الموظف فيه **بريد إلكتروني** (تعديل الموظف) ولم يُربط بحساب من قبل.

## إضافة طبيب جديد بالكامل (من الصفر)

استخدم **معالج إضافة طبيب** فقط — لا تختار دور «طبيب» تحت «حساب جديد» في المستخدمون (يُحوّلك للمعالج تلقائياً).

---

## أخطاء شائعة وحلولها

| المشكلة | السبب | الحل |
|---------|--------|------|
| الطبيب لا يرى مواعيده | لا يوجد ربط User ↔ Staff ↔ Doctor | معالج إضافة طبيب أو تعديل الموظف وربط `user_id` |
| 500 عند حفظ بيانات سريرية | سجل طبيب مكرر أو ترخيص مكرر في العيادة | تأكد من رقم ترخيص فريد؛ راجع `storage/logs/laravel.log` |
| إضافة طبيب من «إضافة موظف» | المسار القديم مُعطَّل | استخدم **إضافة طبيب** فقط |

---

## صلاحيات مطلوبة

| الإجراء | الصلاحية |
|---------|----------|
| معالج إضافة طبيب / قائمة الأطباء | إدارة الأطباء |
| الموظفون (غير طبيب) | إدارة الموظفين |
| المستخدمون | إدارة المستخدمين |

---

## للمطورين

- **المعالج الوحيد لإنشاء طبيب كامل:** `POST /doctors/onboarding` → `DoctorOnboardingService`
- **مزامنة جدول `doctors`:** `StaffDoctorSyncService::syncDoctorForStaff()`
- **ربط المواعيد بحساب الطبيب:** `User::linkedDoctor()`
- **منع إنشاء طبيب من `POST /staff`:** يُحوَّل إلى معالج الإضافة
