# صلاحيات الأدوار — طبيب / استقبال / محاسب

## ما تم التحقق منه آلياً

اختبار `RoleWebAccessTest` يتأكد أن كل دور يفتح صفحاته ويُرفض من الصفحات المحظورة (403).

```bash
php artisan test --filter=RoleWebAccessTest
```

## الطبيب (`doctor`)

**يقدر:**
- لوحة التحكم، **مكتب الطبيب** (`/clinical`)
- المرضى، المواعيد، الزيارات
- مرفقات المرضى (رفع/حذف)
- **أرباحي** (عرض أرباح الطبيب المرتبط فقط)

**ما يقدر:**
- إدارة قائمة الأطباء (إضافة/تعديل أطباء)
- الفواتير، المصروفات، التقارير العامة
- الموظفين، المستخدمين، الإعدادات، النسخ الاحتياطي

**مهم على السيرفر:** حساب الطبيب لازم يكون مربوطاً بسجل **موظف + طبيب**:
1. موظفين → إضافة موظف (دور: طبيب) + ربط بحساب مستخدم
2. أو من `/staff/create?role=doctor` مع إنشاء حساب

بدون الربط: الطبيب يدخل لكن **ما يشوف مواعيده/زياراته** (صفحة فارغة رغم أن المدير يرى مواعيد باسمه).

**إضافة طبيب جديد (طريقة واحدة — البريد مرة واحدة):**

**الأطباء → إضافة طبيب** (`/doctors/onboarding/create`)

- يُنشئ: مستخدم + موظف (طبيب) + سجل طبيب + الربط بينهم.
- **البريد يُكتب مرة واحدة** فقط (للدخول والتواصل).

**إصلاح قيس/أطباء قدامى (يدوي):**

1. **الموظفون** → موظف طبيب مربوط **بحساب المستخدم**.
2. **الأطباء** → نفس الموظف مربوط بسجل الطبيب.
3. تسجيل خروج ودخول للطبيب.

> إن تطابق **البريد** أو **الاسم** بين المستخدم وسجل الطبيب وحدهما في العيادة، النظام يحاول الربط تلقائياً.

## الاستقبال (`receptionist`)

**يقدر:**
- لوحة التحكم، **لوحة الاستقبال** (`/reception`)
- مرضى، أطباء، مواعيد، زيارات
- فواتير، مدفوعات، مصروفات، مخزون، موظفين، رواتب

**ما يقدر:**
- مستخدمي النظام، إعدادات العيادة، سجل التدقيق، النسخ الاحتياطي

---

## المحاسب (`accountant`)

**يقدر:**
- لوحة التحكم
- مرضى، أطباء، مواعيد، زيارات (للربط مع الفواتير)
- فواتير، مدفوعات، مصروفات، تقارير
- أرباح الأطباء، رواتب، مخزون (عرض)
- موظفين (للسياق المالي)

**ما يقدر:**
- مكتب الطبيب (`/clinical`)
- مستخدمي النظام، إعدادات، نسخ احتياطي

---

## إنشاء حسابات على الإنتاج

من حساب **مدير العيادة** (`admin`):

1. **إعدادات → المستخدمون** (أو الموظفون حسب التدفق عندك)
2. أنشئ مستخدمًا واختر الدور: `doctor` / `receptionist` / `accountant`
3. للطبيب: تأكد من **Staff ↔ Doctor ↔ User** مربوطين

بعد `db:seed` الافتراضي يوجد فقط `admin@…` من `SEED_ADMIN_EMAIL` — **لا يوجد طبيب/استقبال جاهز** إلا إذا أنشأتهم أنت.
